# Edunos toolkit — which tool for which job

The owner (Jimmy) speaks French: reply in French. Project CLAUDE.md files override this guide.

## Video
- Sage & Season / a project with its own brand video skill → that project skill (e.g. `trailer-video`).
- Any other video, trailer, ad, reel, explainer → `video-in-code` (canvas film for hand-made looks, Remotion for text-led/social).
- Timing, easing, choreography → read `motion-design`; sequencing → `gsap-timeline`/`gsap-core`; 3D → `threejs-*`.
- Copy a look from references → `design-dna`.
- Websites and app UIs (not videos) → `cast` (one interaction), `paint` (whole look), `bunshin` (whole site, costly; ask first).

## Sound, in this order
1. Find real recordings: `openverse` (CC0 first; CREDITS.csv).
2. Place effects on the picture: `real-sfx` (user's library + bundled UI sounds); full soundtrack with licensed music: `real-sound`.
3. Check by ear before claiming anything about audio: `earshot` (`earshot critique film.mp4`, `earshot rank`).
- Voice-over: Kokoro (`af_heart`, `ff_siwis`…) or Piper, see `video-in-code`.

## Web reading
- Built-in web search/fetch first; X/Twitter, YouTube subtitles, Reddit, Bilibili or a page that won't load → `agent-reach`.

## Agents (subagents)
- Only when the owner asks for agents/a team; otherwise do the work directly (agents cost more).
- 49 active agents (marketing, content, paid social, design, dev, security, QA). 235 more in the toolkit's `agents-library/`: enable one with `sh <toolkit>/install.sh --agent <name>`.

## Persistence
- Cloud sessions are wiped: anything to keep goes to GitHub. Shared tools live in github.com/JimmyDamelio/edunos-claude-toolkit; project work stays in its own repo.
